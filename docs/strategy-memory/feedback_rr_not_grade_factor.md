RR_T1 is **only** used for: (a) hard filter — must be ≥1 to take the trade; (b) reporting. It does NOT cap or degrade grade. A Setup 2 with RR_T1 = 1.2 is still A+ if the structure is clean, delta is strong aligned, and checklist is 100%.

**Why:** on 2026-04-22 I graded a clean Setup 2 LONG as B because RR_T1 was 1.44 < 2. User corrected: "el RR no influye en la calidad del setup" — the RR doesn't influence setup quality. Only structure, delta alignment, and checklist completeness determine grade. The prior rule "RR_T1 < 2 → cap B" was removed from the strategy doc.

**How to apply:**
- When assessing grade, ignore RR magnitude once the ≥1 filter is passed.
- A+/A/B/C is determined by: setup type (S1 max A, S2 up to A+, S3 max B), delta quality (aligned strong = preserve grade; aligned weak = neutral; contradicting = degrade), checklist warnings count (0 = clean, 1 = warning, 2+ = degrade).
- Report RR_T1/T2/T3 as informational, not as grade drivers.
